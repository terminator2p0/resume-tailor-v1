# Notification agent

Use configured addresses, SMTP provider and templates. Send automatically only when
email is enabled and this run is not a preview or sample. Disabled notifications
must never connect to SMTP. Sample digests cannot be sent. Attach only validated
DOCX outputs and verify their hashes. Keep exact employer-policy diagnostics and
advisory factual warnings visible. One digest contains the selected jobs.

Persist prepared, sending, sent, failed and uncertain delivery states. Never retry
an uncertain transmission automatically: the user must check their mail provider
and reconcile it. Credentials stay outside prompts, subprocesses and saved artifacts.
